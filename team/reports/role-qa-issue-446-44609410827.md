### Доказательства и опоры в коде
* **Изоляция режимов (DEMO / LIVE / AI):** В `src/bot.ts` заложен жесткий запрет выполнения торговых тиков в реальном режиме без подтверждения:
  ```typescript
  if (live) {
    state.running = false;
    state.paused = "LIVE временно заблокирован до включения подтверждения каждой сделки и проверки лимитов риска";
    msgs.push(`⏸️ ${state.paused}`);
    return;
  }
  ```
* **Интерфейс и блокировка LIVE:** В `miniapp/web/index.html` кнопка выбора LIVE-режима заблокирована по умолчанию:
  ```html
  <button type="button" data-product-mode="live" aria-pressed="false" disabled aria-disabled="true" title="LIVE заблокирован до проверки полного торгового контракта"><b>LIVE</b><small>Заблокирован</small></button>
  ```
* **AI Companion (Paper-only):** В `src/companion.ts` все запросы обрабатываются изолированно через Durable Objects без доступа к методам реального исполнения ордеров (`trade.*`).
* **Контекст CI Actions:** Проверка `capture-clean-ui.mjs` (Run 44608357999) упала на шаге ожидания видимости навигации из-за регрессии в закрытом PR #455 (`body:has(#kg-companion-screen.is-active) #kg-nav{display:none!important}`), который скрывал навигацию на всем Companion home. Данный PR закрыт и **не входит** в `main`.
