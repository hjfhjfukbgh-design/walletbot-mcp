#### 3. Доказательства (точный анализ путей и символов)
* **Блокировка LIVE-режима:** В файле `src/bot.ts` (строки 42–47) явно прописано принудительное отключение авто-исполнения для реального режима:
  ```ts
  const live = state.mode === "live";
  if (live) {
    state.running = false;
    state.paused = "LIVE временно заблокирован до включения подтверждения каждой сделки и проверки лимитов риска";
    msgs.push(`⏸️ ${state.paused}`);
    return;
  }
  ```
* **Защита ручных/демо сделок:** В файле `src/manual.ts` реализованы строгие проверки лимитов риска перед открытием позиций (`checkOpen`, контроль маржи, плеча и доступного эквити).
* **Многопользовательская изоляция:** В `src/tenants.ts` реализован механизм `tenantEnv`, изолирующий KV-пространства по Telegram `userId`, что исключает утечку данных между пользователями мини-приложения.

#### 4. Риски и пробелы
1. **Отсутствие Runtime-подтверждения:** Код не был запущен в рамках текущей сессии (`NOT RUN`), что оставляет риск скрытых синтаксических ошибок или проблем сборки Worker'а (Wrangler).
2. **Недоступность PR #228:** Из-за отсутствия `GH_TOKEN` невозможно сопоставить изменения с историей коммитов/ревью в GitHub.
