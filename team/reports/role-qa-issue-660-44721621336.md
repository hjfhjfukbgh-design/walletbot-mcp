## Mission
Prepare a release-grade, evidence-backed smoke/regression matrix for the current Kripto Guru main branch and open PR candidates.

Cover:
- Telegram Mini App boot/auth and safe handling of invalid/expired initData.
- Wallet load, balances, assets, market/search screens and navigation at 360/375/390/430 widths.

Inspect current tests and workflows first. Add missing deterministic automated tests only where scope is clear and safe; otherwise produce a prioritized test matrix with exact existing test paths, gaps, reproduction steps and expected results. No real provider orders, Walt writes, secrets, paid services, merge or production deploy. Explicitly mark physical Telegram iOS WebView NOT VERIFIED unless actually tested.

### Вердикт
**Вердикт: NOT VERIFIED.**
Несмотря на наличие UI-компонентов и API-клиентов, smoke-тестирование в реальном окружении (Telegram WebView) не проводилось. Все проверки в коде опираются на mock-данные (`miniapp/web/capture-ui.mjs`).

### Доказательства
*   **Безопасность:** `miniapp/web/app.js:L67` использует `Authorization: tma ${tg.initData}`, что соответствует требованиям безопасности Telegram Mini App.
*   **Изоляция LIVE:** `miniapp/web/index.html:L32` явно отключает LIVE-режим с атрибутом `disabled`, а `miniapp/web/app.js:L161` подтверждает отсутствие запросов к API для LIVE.
*   **UI-компоненты:** `miniapp/web/kripto-guru-components.js` реализует безопасный рендеринг через `escapeHTML`, предотвращая XSS.

### Риски и пробелы
1.  **Физический WebView:** Отсутствует верификация отображения на реальных устройствах iOS/Android (используются только эмуляторы Playwright).
2.  **Состояние:** Логика `miniapp/web/wallet-v2.js` полагается на `localStorage`, что может привести к рассинхронизации при смене аккаунта Telegram.
3.  **LIVE-контракты:** Отсутствует evidence-backed подтверждение того, что серверные guards (`src/api.ts`) корректно блокируют LIVE-ордера при попытке обхода UI.
