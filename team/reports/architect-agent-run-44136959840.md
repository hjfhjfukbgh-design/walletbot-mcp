### 1. Архитектурный вердикт
Проект `walletbot-mcp` представляет собой serverless-приложение на Cloudflare Workers с гибридной архитектурой: Telegram Webhook / Mini App и торговый движок с Cron-триггерами (каждые 5 минут). 
* **Сильные стороны:** Четкое разделение ответственности (`src/index.ts`, `src/api.ts`, `src/service.ts`, `src/strategy/grid.ts`, `src/trading/engine.ts`), использование защищенного хранилища KV (изоляция по `tenantEnv`), строгая калькуляция с фиксированной точкой (`src/trading/money.ts`), а также защитный контур для LIVE-торговли (`setMode` блокирует реальные сделки без полноценного шлюза).
* **Слабые стороны и риски:** Отсутствие единой очереди задач (task queue) в виде персистентной структуры для асинхронных бэкграунд-задач вне Cron, риск гонки состояний в KV при параллельном вызове API и тиков, а также жесткие ограничения GitHub Actions и Cloudflare (лимиты CPU/KV).
* **Безопасность:** Секреты (`API_SECRET`, токены Telegram) изолированы через Wrangler / GitHub Actions Secrets. LIVE-торговля заблокирована на уровне кода и бизнес-логики. Бюджет: 0 (используются только бесплатные ресурсы Cloudflare и существующие инструменты).

### 2. Схема компонентов и поток задачи

```
[ Telegram User ] 
       │ (Сообщение / Команда)
       ▼
[ Telegram Serverless (tgcloud) ] 
       │ (POST /api/telegram, заголовок X-Api-Key)
       ▼
[ Cloudflare Worker (src/index.ts) ] 
       │ 
       ├─► [ API Router (src/api.ts) ] ──► [ KV Namespace (STATE) / Tenant Isolation ]
       │
       └─► [ Cron / Scheduled (каждые 5 мин) ] ──► [ Trading Engine / Strategy Tick ] ──► [ Walt MCP / Paper Simulation ]
```

* **Поток задачи:**
  1. Входной запрос поступает через Webhook Telegram или Mini App (`/api/*`).
  2. Запрос верифицируется (проверка `X-Api-Key` или `initData` Telegram).
  3. Контекст изолируется по пользователю (`tenantEnv`), данные читаются/пишутся в KV.
  4. Фоновые расчёты сетки и тиков выполняются по таймеру (`scheduled` / Cron) или инициируются пользователем, используя чистую математику (`src/trading/money.ts`) без платных внешних API.

### 4. Текущие подтверждённые возможности и пробелы

* **Подтвержденная функциональность (Fact):**
  * Telegram Webhook и обработка команд (`src/commands.ts`, `src/index.ts`).
  * Изоляция данных пользователей через префиксы KV в `src/tenants.ts`.
  * Демо-торговый движок с фиксированной точкой (`src/trading/money.ts`, `src/trading/engine.ts`).
  * Тесты на Vitest и проверка типов TypeScript (`npm test`, `npm run typecheck`).
  * Защита маршрутов Mini App заголовком `X-Api-Key` / `tma` initData.
* **Пробелы и гипотезы (Hypothesis / Gap):**
  * *Гипотеза:* Производительность KV при высокой частоте запросов от Mini App достаточна без выделенного кэша в памяти Worker (требует нагрузочного теста, подтверждено ограничением KV 1000 записей/день для бесплатного тарифа).
  * *Пробел:* Отсутствие комплексных интеграционных тестов для полного цикла OAuth-авторизации Walt MCP в изолированном окружении (зависит от внешнего API Walt, который не может быть замокан локально без эмулятора).
  * *Пробел:* Поведение Mini App на реальных слабых мобильных устройствах под iOS при нестабильном интернет-соединении (требует ручного тестирования в Telegram WebView).

### 5. Риски и меры

1. **Риск превышения лимитов Cloudflare KV (бесплатный тариф: 1000 записей/день).**
   * *Мера:* Минимизация частых записей в KV; запись состояния сетки только при изменении ключевых параметров или по Cron (1 раз в 5 минут, ~288 записей в сутки, что укладывается в лимит).
2. **Риск рассинхронизации состояния при параллельных запросах.**
   * *Мера:* Использование изолированных префиксов тенантов в `src/tenants.ts` и атомарных операций хранилища.
3. **Риск случайного включения LIVE-торговли.**
   * *Мера:* Жёсткая программная блокировка в `src/service.ts` (`setMode`), требующая явного подтверждения и отсутствия автоматических триггеров для реального исполняемого кода без шлюза.
4. **Риск исчерпания бюджетов или платных вызовов.**
   * *Мера:* Бюджет 0 соблюдается строго: внешние платные API и сервисы не подключаются.
