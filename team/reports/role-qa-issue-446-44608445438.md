### Доказательства и опоры в коде
* **Разрешения и адаптивность:** Заданы через метатег `viewport` в `miniapp/web/index.html`: `width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no, viewport-fit=cover`.
* **Безопасность тем:** В `miniapp/web/index.html` реализован безопасный скрипт инициализации темы (`localStorage` -> `data-theme`), предотвращающий мигание экрана.
* **Изоляция режимов (DEMO / LIVE / AI):** В `miniapp/web/index.html` кнопка `LIVE` явно заблокирована (`disabled aria-disabled="true"`), а в `src/bot.ts` срабатывает защитный барьер:
  ```typescript
  if (live) {
    state.running = false;
    state.paused = "LIVE временно заблокирован до включения подтверждения каждой сделки и проверки лимитов риска";
    msgs.push(`⏸️ ${state.paused}`);
    return;
  }
  ```
* **Интеграция с Telegram BackButton:** Настроена в `miniapp/web/app.js`:
  ```javascript
  const telegramBackButton = tg?.BackButton ?? null;
  if (telegramBackButton) {
    document.documentElement.classList.add('telegram-native-back');
    telegramBackButton.onClick?.(() => {
      const action = telegramBackAction;
      telegramBackAction = null;
      telegramBackButton.hide?.();
      action?.();
    });
  }
  ```

### Риски и пробелы (Gaps)
1. **Расхождение рендеринга:** Браузерный эмулятор Playwright в тестах (`capture-clean-ui.mjs`) не учитывает особенности поведения `Telegram WebApp` внутри нативных WebView на iOS (Safari UI) и Android (Chrome WebView), особенно в части появления виртуальной клавиатуры и перекрытия фиксированной нижней навигации (`bottom-nav`).
2. **Отсутствие CI-артефактов:** В задачах отсутствуют идентификаторы прогонов GitHub Actions (`Workflow Run IDs`), подтверждающие успешное прохождение визуальных регрессионных тестов.
