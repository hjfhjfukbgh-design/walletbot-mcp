# Диспетчер ИИ-команды — прототип

## Текущий режим: DRY RUN

Workflow `.github/workflows/ai-team-dispatcher.yml` запускается вручную через GitHub Actions.

Он:
- проверяет наличие `team/TASKS.md`;
- выводит открытые задачи в сводку запуска;
- явно показывает, что LLM-провайдер не подключён;
- не вызывает внешние API;
- не изменяет Issues, файлы, ветки или Pull Requests;
- не имеет доступа к secrets и не запускает deploy.

## Почему пока нет расписания 24/7

Периодический запуск без подключённой модели не создаёт ИИ-агентов — он только повторяет пустую проверку. Сначала нужно подтвердить бесплатного провайдера, доступные модели и фактические лимиты. Затем диспетчер получит общий ограничитель запросов/токенов, учёт по ролям, паузу при 429/квоте и отдельный kill switch.

## Следующие этапы

1. Проверить dry-run на GitHub Actions.
2. Утвердить бесплатную модель и её условия использования.
3. Добавить API-ключ только в GitHub Actions Secrets (никогда не в файлы репозитория).
4. Реализовать одного агента с лимитом расходов 0 и жёстким лимитом запросов.
5. Проверить результат и независимый QA; лишь затем подключать остальные роли.

До отдельного разрешения CEO запрещены merge в `main`, production deploy и любые реальные торговые действия. LIVE нельзя активировать агентам.
