## P0 — управление и безопасность

- [x] Создать рабочую ветку штаба отдельно от main.
- [x] Зафиксировать роли, протокол и исходный аудит.

## P1 — качество Kripto Guru

- [ ] Составить карту текущих экранов Mini App и API-контрактов на основе main и актуальных PR.
- [ ] Выделить подтверждённые production-дефекты отдельно от незавершённых визуальных задач.
- [ ] Для каждого P0-дефекта подготовить воспроизводимый тест и критерии приёмки.
- [ ] Проверить, что DEMO остаётся единственным доступным торговым режимом, LIVE заблокирован, реальные ордера невозможны.

## P2 — автоматизация команды с бюджетом 0

- [ ] Инвентаризировать существующие GitHub Actions и доступные бесплатные квоты.
- [ ] Спроектировать диспетчер задач на GitHub Issues/Projects без платных API.
- [ ] Проверить варианты бесплатного LLM-исполнения; не добавлять интеграцию до проверки лимитов, лицензии, секретов и риска расходов.
- [ ] Добавить автоматические отчёты только для реально выполняемых проверок; не имитировать ИИ-работу.

## Правила приоритета

Безопасность и сохранность данных важнее новых функций. Надёжность DEMO важнее декоративных улучшений. Новые функции не должны обходить ограничения LIVE или создавать ложные обещания пользователю.
