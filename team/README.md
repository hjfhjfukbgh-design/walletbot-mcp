# Kripto Guru — штаб команды

Этот каталог — единый источник рабочих правил команды проекта.

## Принцип работы

- Владелец проекта (CEO) определяет цели, бюджет и принимает продуктовые решения.
- Главный руководитель (LEAD) превращает цели в проверяемые задачи, распределяет работу и контролирует качество.
- Специализированные роли помогают выполнять анализ, разработку, тестирование и аудит.
- GitHub хранит задачи, решения, изменения и доказательства проверок.

## Важное ограничение автономности

Роли в документации — это протокол организации работы, а не запущенные независимые ИИ-процессы. GitHub Actions может выполнять автоматические сценарии, но сам по себе не предоставляет бесплатные LLM-вызовы и не пробуждает отдельные чаты ChatGPT. До появления проверенного бесплатного исполнителя задачи не должны изображаться как выполненные автономными агентами.
